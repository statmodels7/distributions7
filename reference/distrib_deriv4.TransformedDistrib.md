# Transformed Fourth Derivatives

As
[`the third`](https://statmodels7.github.io/distributions7/reference/distrib_deriv3.TransformedDistrib.md),
at fourth order.

## Arguments

- distrib:

  A `TransformedDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list of the parent's parameters.

- expected:

  Logical; if `TRUE`, the expected derivatives.

## Value

A named list of derivative components.
