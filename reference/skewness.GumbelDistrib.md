# Skewness of the Gumbel Distribution

Closed form: \\12\sqrt{6}\\\zeta(3)/\pi^3 \approx 1.1395\\, the same for
every location and scale.

## Arguments

- x:

  A
  [`GumbelDistrib`](https://statmodels7.github.io/distributions7/reference/GumbelDistrib.md).

- theta:

  A named list of parameters.

- ...:

  Unused.

## Value

A numeric vector.
