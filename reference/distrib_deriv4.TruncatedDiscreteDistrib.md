# Truncated Fourth Derivatives (Discrete)

As
[`the third`](https://statmodels7.github.io/distributions7/reference/distrib_deriv3.TruncatedDiscreteDistrib.md),
at fourth order.

## Arguments

- distrib:

  A `TruncatedDiscreteDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list of the parent's parameters.

- expected:

  Logical; if `TRUE`, the expected derivatives.

## Value

A named list of derivative components.
