# Skew Normal Density in the Centered Parametrization

The skew normal density at the implied direct parameters.

## Arguments

- distrib:

  A `SkewNormal2Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list with `mu`, `sigma` and `gamma1`.

- log:

  Logical; if `TRUE`, returns the log-density.

## Value

A numeric vector.
