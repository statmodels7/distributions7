# Exponential Random Generation

Draws from the exponential distribution through
[`rexp`](https://rdrr.io/r/stats/Exponential.html).

## Arguments

- distrib:

  An `ExponentialDistrib` object.

- n:

  The number of draws.

- theta:

  A list containing the parameter `mu`.

## Value

A numeric vector of length `n`.
