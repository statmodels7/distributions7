# Zero-Inflated Fourth Derivatives

As
[`the third`](https://statmodels7.github.io/distributions7/reference/distrib_deriv3.ZeroInflatedDistrib.md),
at fourth order.

## Arguments

- distrib:

  A `ZeroInflatedDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list with the parent's parameters followed by `zi`.

- expected:

  Logical; if `TRUE`, the expected derivatives.

## Value

A named list of derivative components.
