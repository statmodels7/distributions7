# Skewness of the NB1 Negative Binomial Distribution

Closed form: \\(1+2\theta)/\sqrt{\mu(1+\theta)}\\, which tends to the
Poisson \\1/\sqrt{\mu}\\ as \\\theta \to 0\\.

## Arguments

- x:

  A `NegBin1Distrib`.

- theta:

  A named list of parameters.

- ...:

  Unused.

## Value

A numeric vector.
