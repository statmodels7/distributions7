# Inverse Gaussian Quantile Function in Mean and Shape

The inverse gaussian quantile function at dispersion \\1/\lambda\\.

## Arguments

- distrib:

  An `InvGauss2Distrib` object.

- p:

  A numeric vector of probabilities.

- theta:

  A list with `mu` and `lambda`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, `p` is a log-probability.

- ...:

  Unused.

## Value

A numeric vector.
