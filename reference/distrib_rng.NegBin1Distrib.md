# NB1 Random Generation

[`rnbinom`](https://rdrr.io/r/stats/NegBinomial.html) at the same size
and probability.

## Arguments

- distrib:

  A `NegBin1Distrib` object.

- n:

  The number of draws.

- theta:

  A list containing `mu` and `theta`.

## Value

A numeric vector of length `n`.
