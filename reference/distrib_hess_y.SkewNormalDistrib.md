# Skew Normal Response Second Derivative

Closed form: \\\partial^2 \ell / \partial y^2 = (\alpha^2 R' -
1)/\sigma^2\\.

## Arguments

- distrib:

  A `SkewNormalDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing `mu`, `sigma` and `alpha`.

## Value

A numeric vector.
