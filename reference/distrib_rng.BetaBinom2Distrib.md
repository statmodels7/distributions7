# Beta-Binomial Random Generation in Its Shapes

A beta draw for the probability, then a binomial draw.

## Arguments

- distrib:

  A `BetaBinom2Distrib` object.

- n:

  The number of draws.

- theta:

  A list with `alpha` and `beta`.

## Value

A numeric vector of counts.
