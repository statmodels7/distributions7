# The Shape and Rate a Mean and Dispersion Imply

\\a = 1/\phi\\ and \\b = 1/(\phi\mu)\\, which is what makes the variance
\\\phi\mu^2\\.

## Usage

``` r
gamma1_shape_rate(theta)
```

## Arguments

- theta:

  A list with `mu` and `phi`.

## Value

A list with `shape` and `rate`.
