# Derivatives of the Standard Normal Distribution Function

Returns the factor \\h_m\\ in \\\Phi^{(m)}(x) = h_m(x)\varphi(x)\\ for
\\m = 1, \ldots, 4\\, the Hermite polynomials.

## Usage

``` r
phi_hermite(x, m)
```

## Arguments

- x:

  A numeric vector.

- m:

  The order, 1 to 4.

## Value

A numeric vector.
