# Kurtosis of the NB1 Negative Binomial Distribution

Closed form: excess \\6\theta/\mu + 1/\\\mu(1+\theta)\\\\, which tends
to the Poisson \\1/\mu\\ as \\\theta \to 0\\.

## Arguments

- x:

  A `NegBin1Distrib`.

- theta:

  A named list of parameters.

- ...:

  Unused.

## Value

A numeric vector.
