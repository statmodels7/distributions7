# Elastic-Net Second Response Derivative

\\\ell^{(yy)} = -c\\: the absolute value contributes nothing away from
the location, so the curvature in the response is the Gaussian part
alone.

## Arguments

- distrib:

  An `EnetDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing `mu`, `lambda` and `alpha`.

## Value

A numeric vector.
