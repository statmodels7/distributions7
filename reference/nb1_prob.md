# The Success Probability Behind an NB1 Dispersion

\\1/(1+\theta)\\, the value that makes the variance-to-mean ratio
\\1+\theta\\ at every mean.

## Usage

``` r
nb1_prob(theta)
```

## Arguments

- theta:

  The dispersion, a positive numeric vector.

## Value

A numeric vector in \\(0, 1)\\.
