# Gaussian Random Generation in Mean and Precision

Delegates to [`rnorm`](https://rdrr.io/r/stats/Normal.html).

## Arguments

- distrib:

  A `Gaussian3Distrib` object.

- n:

  The number of draws.

- theta:

  A list with `mu` and `tau`.

## Value

A numeric vector.
