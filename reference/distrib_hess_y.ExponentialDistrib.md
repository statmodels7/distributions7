# Exponential Response Hessian

\$\$\dfrac{\partial^2 \ell}{\partial y^2} = 0\$\$ the log-density being
linear in the response.

## Arguments

- distrib:

  An `ExponentialDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameter `mu`.

- ...:

  Unused.

## Value

A numeric vector of zeros.
