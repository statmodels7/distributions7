# Inverse-Gaussian Response Second Derivative

Closed-form \\\partial^2 \ell / \partial y^2 = 3/(2y^2) - 1/(\phi
y^3)\\.

## Arguments

- distrib:

  An `InvGauss1Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `phi`.

## Value

A numeric vector.
