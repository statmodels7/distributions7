# Generalised Pareto Random Generation

Inverse transform, the quantile function being elementary.

## Arguments

- distrib:

  A `GPDDistrib` object.

- n:

  The number of draws.

- theta:

  A list containing `sigma` and `xi`.

## Value

A numeric vector of length `n`.
