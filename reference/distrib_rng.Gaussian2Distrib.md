# Gaussian Random Generation in Mean and Variance

Delegates to [`rnorm`](https://rdrr.io/r/stats/Normal.html).

## Arguments

- distrib:

  A `Gaussian2Distrib` object.

- n:

  The number of draws.

- theta:

  A list with `mu` and `sigma2`.

## Value

A numeric vector.
