# Cauchy Response Second Derivative

Closed-form \\\partial^2 \ell / \partial y^2 = 2(r^2 -
\sigma^2)/(\sigma^2 + r^2)^2\\, \\r = y - \mu\\.

## Arguments

- distrib:

  A `CauchyDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `sigma`.

## Value

A numeric vector.
