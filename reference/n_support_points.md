# Number of Points in a Discrete Support

How many points the distribution's support contains, `Inf` when it is
unbounded.

## Usage

``` r
n_support_points(distrib)
```

## Arguments

- distrib:

  An object inheriting from class `"distrib"`.

## Value

A single number.
