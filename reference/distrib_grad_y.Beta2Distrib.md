# Beta Response Derivatives in Its Shapes

\\\partial\ell/\partial y = (\alpha-1)/y - (\beta-1)/(1-y)\\.

## Arguments

- distrib:

  A `Beta2Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list with `alpha` and `beta`.

- ...:

  Unused.

## Value

A numeric vector.
