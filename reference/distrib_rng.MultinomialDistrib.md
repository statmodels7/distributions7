# Multinomial Random Generation

[`rmultinom`](https://rdrr.io/r/stats/Multinom.html), transposed so that
one row is one observation.

## Arguments

- distrib:

  A `MultinomialDistrib` object.

- n:

  The number of draws.

- theta:

  A named list of parameters.

## Value

A matrix with `n` rows.
