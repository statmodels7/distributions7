# Is This a Fixed-Parameter Wrapper?

`TRUE` for a distribution produced by
[`fixed`](https://statmodels7.github.io/distributions7/reference/fixed.md),
in any of its three forms.

## Usage

``` r
is_fixed(distrib)
```

## Arguments

- distrib:

  An object inheriting from class `"distrib"`.

## Value

A single logical.
