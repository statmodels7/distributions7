# Hurdle Fourth Derivatives

As
[`the third`](https://statmodels7.github.io/distributions7/reference/distrib_deriv3.ZeroAdjustedDiscreteDistrib.md),
at fourth order.

## Arguments

- distrib:

  A `ZeroAdjustedDiscreteDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list with the parent's parameters followed by `za`.

- expected:

  Logical; if `TRUE`, the expected derivatives.

## Value

A named list of derivative components.
