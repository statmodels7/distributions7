# Gamma Random Generation in Mean and Dispersion

Delegates to [`rgamma`](https://rdrr.io/r/stats/GammaDist.html).

## Arguments

- distrib:

  A `Gamma1Distrib` object.

- n:

  The number of draws.

- theta:

  A list with `mu` and `phi`.

## Value

A numeric vector.
