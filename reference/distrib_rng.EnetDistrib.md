# Elastic-Net Random Generation

Inverse transform on the closed-form quantile function.

## Arguments

- distrib:

  An `EnetDistrib` object.

- n:

  The number of draws.

- theta:

  A list containing `mu`, `lambda` and `alpha`.

## Value

A numeric vector of draws.
