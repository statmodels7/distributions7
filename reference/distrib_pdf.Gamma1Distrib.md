# Gamma Density in Mean and Dispersion

The gamma density at shape \\a = 1/\phi\\ and rate \\b = 1/(\phi\mu)\\.

## Arguments

- distrib:

  A `Gamma1Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list with `mu` and `phi`.

- log:

  Logical; if `TRUE`, returns the log-density.

## Value

A numeric vector.
