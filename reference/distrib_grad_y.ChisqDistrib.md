# Chi-Squared Response Gradient

\$\$\dfrac{\partial \ell}{\partial y} = \dfrac{\mu/2 - 1}{y} -
\dfrac{1}{2}\$\$

## Arguments

- distrib:

  A `ChisqDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameter `mu`.

- ...:

  Unused.

## Value

A numeric vector.
