# Beta Random Generation in Its Shapes

Delegates to [`rbeta`](https://rdrr.io/r/stats/Beta.html).

## Arguments

- distrib:

  A `Beta2Distrib` object.

- n:

  The number of draws.

- theta:

  A list with `alpha` and `beta`.

## Value

A numeric vector.
