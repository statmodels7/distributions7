# Exponential Response Gradient

\$\$\dfrac{\partial \ell}{\partial y} = -\dfrac{1}{\mu}\$\$

## Arguments

- distrib:

  An `ExponentialDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameter `mu`.

- ...:

  Unused.

## Value

A numeric vector.
