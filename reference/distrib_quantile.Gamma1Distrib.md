# Gamma Quantile Function in Mean and Dispersion

The gamma quantile function at the implied shape and rate.

## Arguments

- distrib:

  A `Gamma1Distrib` object.

- p:

  A numeric vector of probabilities.

- theta:

  A list with `mu` and `phi`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, `p` is given as a log-probability.

- ...:

  Unused.

## Value

A numeric vector.
