# No Intercept Needs a Start of Its Own

The base method: an empty list, the intercept-only fit being the start
for every parameter.

## Arguments

- distrib:

  A
  [`distrib()`](https://statmodels7.github.io/distributions7/reference/distrib.md)
  object.

- y:

  The response. Unused.

- ...:

  Unused.

## Value

An empty list.
