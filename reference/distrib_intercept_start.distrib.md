# Default Intercept Starting Values

The base method returns an empty list, because the intercept-only fit is
the start for every parameter.

## Arguments

- distrib:

  A
  [`distrib()`](https://statmodels7.github.io/distributions7/reference/distrib.md)
  object.

- y:

  The response. It is unused.

- ...:

  Unused.

## Value

An empty list.

## See also

[`distrib_intercept_start()`](https://statmodels7.github.io/distributions7/reference/distrib_intercept_start.md)
for the generic.
