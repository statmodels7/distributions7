# Variance-Covariance Matrix of a Maximum-Likelihood Fit

Variance-Covariance Matrix of a Maximum-Likelihood Fit

## Arguments

- object:

  A
  [`distrib_fit`](https://statmodels7.github.io/distributions7/reference/distrib_fit_class.md)
  object.

- scale:

  Either `"parameter"` (default) or `"link"`.

- ...:

  Unused.

## Value

A variance-covariance matrix.
