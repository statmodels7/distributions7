# Truncated Mean of Products of Scores

\\\mathbb{E}\_T\[s_i s_j\]\\ for every Hessian component, by quadrature.

## Usage

``` r
trunc_score_prod_mean(distrib, theta)
```

## Arguments

- distrib:

  A truncated distribution object.

- theta:

  A named list of parameters.

## Value

A named list, one component per Hessian entry.
