# Weibull Response Second Derivative

Closed form: \\\partial^2 \ell / \partial y^2 = -(\sigma - 1)(1 + \sigma
u)/y^2\\.

## Arguments

- distrib:

  A `Weibull1Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `sigma`.

## Value

A numeric vector.
