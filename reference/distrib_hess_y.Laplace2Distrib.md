# Laplace Response Second Derivative in Location and Rate

Closed-form \\\partial^2 \ell / \partial y^2 = 0\\ (almost everywhere).

## Arguments

- distrib:

  A `Laplace2Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `lambda`.

## Value

A numeric vector of zeros.
