# Gamma Response Second Derivative

Closed-form \\\partial^2 \ell / \partial y^2 = -(\alpha-1)/y^2\\,
\\\alpha = \mu^2/\sigma^2\\.

## Arguments

- distrib:

  A `GammaDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `sigma2`.

## Value

A numeric vector.
