# Truncated Third Derivatives (Discrete)

As the continuous case, with the expectations taken by summation.

## Arguments

- distrib:

  A `TruncatedDiscreteDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list of the parent's parameters.

- expected:

  Logical; if `TRUE`, the expected derivatives.

## Value

A named list of derivative components.
