# Gumbel Response Second Derivative

Closed form: \\\partial^2 \ell / \partial y^2 = -w/\sigma^2\\.

## Arguments

- distrib:

  A `GumbelDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `sigma`.

## Value

A numeric vector.
