# Skew t Response Second Derivative

Closed form: \\\partial^2 \ell / \partial y^2 = D'/\sigma^2\\.

## Arguments

- distrib:

  A `SkewTDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing `mu`, `sigma`, `alpha` and `nu`.

## Value

A numeric vector.
