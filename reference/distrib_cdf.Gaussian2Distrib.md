# Gaussian Distribution Function in Mean and Variance

The normal distribution function, with the standard deviation taken as
the square root of the variance parameter.

## Arguments

- distrib:

  A `Gaussian2Distrib` object.

- q:

  A numeric vector of quantiles.

- theta:

  A list with `mu` and `sigma2`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, returns log-probabilities.

- ...:

  Unused.

## Value

A numeric vector.
