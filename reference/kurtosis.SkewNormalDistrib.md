# Kurtosis of the Skew Normal Distribution

Closed form, excess: \\2(\pi - 3)(b\delta)^4/(1 - b^2\delta^2)^2\\. It
is non-negative and bounded above by about \\0.8692\\.

## Arguments

- x:

  A
  [`SkewNormalDistrib`](https://statmodels7.github.io/distributions7/reference/SkewNormalDistrib.md).

- theta:

  A named list of parameters.

- ...:

  Unused.

## Value

A numeric vector.
