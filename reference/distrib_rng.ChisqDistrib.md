# Chi-Squared Random Generation

Draws through [`rchisq`](https://rdrr.io/r/stats/Chisquare.html).

## Arguments

- distrib:

  A `ChisqDistrib` object.

- n:

  The number of draws.

- theta:

  A list containing the parameter `mu`.

## Value

A numeric vector of length `n`.
