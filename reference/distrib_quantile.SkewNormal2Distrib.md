# Skew Normal Quantile Function in the Centred Parametrisation

The parent's quantile function at the implied parameters.

## Arguments

- distrib:

  A `SkewNormal2Distrib` object.

- p:

  A numeric vector of probabilities.

- theta:

  A list with `mu`, `sigma` and `gamma1`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, `p` is a log-probability.

- ...:

  Passed on.

## Value

A numeric vector.
