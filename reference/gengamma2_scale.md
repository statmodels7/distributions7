# The Scale of a Generalized Gamma with a Given Mean

Returns \\a = m\\\Gamma(d/p)/\Gamma((d+1)/p)\\, formed on the log scale
with [`lgamma()`](https://rdrr.io/r/base/Special.html).

## Usage

``` r
gengamma2_scale(theta)
```

## Arguments

- theta:

  A list with the mean, the shape and the power, in that order.

## Value

A numeric vector of scales.
