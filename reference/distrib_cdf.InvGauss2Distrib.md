# Inverse Gaussian Distribution Function in Mean and Shape

The inverse gaussian distribution function at dispersion \\1/\lambda\\.

## Arguments

- distrib:

  An `InvGauss2Distrib` object.

- q:

  A numeric vector of quantiles.

- theta:

  A list with `mu` and `lambda`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, returns log-probabilities.

- ...:

  Unused.

## Value

A numeric vector.
