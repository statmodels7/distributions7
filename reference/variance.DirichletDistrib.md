# Variance of a Dirichlet

The covariance matrix
[`mv_sigma`](https://statmodels7.github.io/distributions7/reference/mv_location.md)
carries, singular because the coordinates sum to one.

## Arguments

- x:

  A `DirichletDistrib` object.

- theta:

  A named list of parameters.

- ...:

  Unused.

## Value

A symmetric \\p \times p\\ matrix.
