# The Shape a Skew Normal's Moments Depend On

Returns \\\delta = \alpha/\sqrt{1+\alpha^2}\\ and the product
\\b\delta\\ with \\b = \sqrt{2/\pi}\\, from which every moment of a skew
normal follows.

## Usage

``` r
skewnormal_delta(alpha)
```

## Arguments

- alpha:

  The shape parameter.

## Value

A list with `delta` and `bd`.
