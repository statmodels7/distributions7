# Mean of the Weibull Distribution

Closed form: \\\mu\\\Gamma(1 + 1/\sigma)\\. The scale \\\mu\\ is not the
mean, which is what this method reports.

## Arguments

- x:

  A
  [`WeibullDistrib`](https://statmodels7.github.io/distributions7/reference/WeibullDistrib.md).

- theta:

  A named list of parameters.

- ...:

  Unused.

## Value

A numeric vector.
