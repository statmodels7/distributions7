# Describe a Trial Parameter Value

Renders the point a map was probed at, so that a failure names it
instead of leaving the caller to guess.

## Usage

``` r
.describe_probe(probe)
```

## Arguments

- probe:

  A named list of parameter values.

## Value

A single string.
