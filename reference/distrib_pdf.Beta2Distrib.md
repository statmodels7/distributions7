# Beta Density in Its Shapes

\$\$f(y) = \dfrac{y^{\alpha-1}(1-y)^{\beta-1}}{B(\alpha, \beta)}\$\$

## Arguments

- distrib:

  A `Beta2Distrib` object.

- y:

  A numeric vector of observations in \\(0, 1)\\.

- theta:

  A list with `alpha` and `beta`.

- log:

  Logical; if `TRUE`, returns the log-density.

## Value

A numeric vector.
