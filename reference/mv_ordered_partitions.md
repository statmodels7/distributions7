# Ordered Partitions of a Set of Positions

All ordered partitions of a set of positions into nonempty blocks: the
set partitions, each in every ordering of its blocks. This is how the
derivative of an inverse distributes its differentiations, \\P_t = \sum
(-1)^q P A\_{B_1} P \cdots A\_{B_q} P\\.

## Usage

``` r
mv_ordered_partitions(pos)
```

## Arguments

- pos:

  An integer vector of positions.

## Value

A list of lists of integer vectors.
