# Generalized Pareto Response Derivatives

Closed form: \\\ell^{(y)} = -(\xi+1)/(\sigma t)\\ and \\\ell^{(yy)} =
\xi(\xi+1)/(\sigma t)^2\\, with \\t = 1 + \xi y/\sigma\\.

## Arguments

- distrib:

  A `GPDDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing `sigma` and `xi`.

- ...:

  Unused.

## Value

A numeric vector.
