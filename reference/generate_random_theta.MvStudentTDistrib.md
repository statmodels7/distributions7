# Random Parameters for a Multivariate Student t

A location near the origin, a scale near the identity, and degrees of
freedom in a range where the family is heavy-tailed but the likelihood
is still well conditioned.

## Arguments

- distrib:

  A
  [`MvStudentTDistrib`](https://statmodels7.github.io/distributions7/reference/MvStudentTDistrib.md)
  object.

- ...:

  Unused.

## Value

A named list of scalars.
