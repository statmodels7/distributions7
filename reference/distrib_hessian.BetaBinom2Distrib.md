# Beta-Binomial Analytical Observed Hessian in Its Shapes

The same sums with the trigamma function.

## Arguments

- distrib:

  A `BetaBinom2Distrib` object.

- y:

  A numeric vector of counts.

- theta:

  A list with `alpha` and `beta`.

- scale:

  Either `"parameter"` or `"link"`; handled by the generic.

- ...:

  Unused.

## Value

A named list of second derivatives.
