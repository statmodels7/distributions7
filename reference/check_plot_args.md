# The Arguments That a Graph Accepts

Signals an error when `...` is not empty, and when `legend` is not
`TRUE` or `FALSE`. The graphs take no graphical arguments: the returned
ggplot2 object is modified instead.

## Usage

``` r
check_plot_args(legend, ...)
```

## Arguments

- legend:

  The value of the argument `legend`.

- ...:

  The `...` of the calling method.

## Value

`NULL`, invisibly.
