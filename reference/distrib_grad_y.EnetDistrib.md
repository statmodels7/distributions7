# Elastic-Net Response Derivatives

\\\ell^{(y)} = -a\\\mathrm{sgn}(y-\mu) - c(y-\mu)\\, undefined at the
location.

## Arguments

- distrib:

  An `EnetDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing `mu`, `lambda` and `alpha`.

## Value

A numeric vector.
