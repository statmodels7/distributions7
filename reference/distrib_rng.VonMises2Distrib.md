# von Mises Random Generation in the Resultant Length

Delegates to the concentration parametrization.

## Arguments

- distrib:

  A `VonMises2Distrib` object.

- n:

  The number of draws.

- theta:

  A list with `mu` and `rho`.

## Value

A numeric vector of angles.
