# Beta Quantile Function in Its Shapes

The inverse of the incomplete beta function.

## Arguments

- distrib:

  A `Beta2Distrib` object.

- p:

  A numeric vector of probabilities.

- theta:

  A list with `alpha` and `beta`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, `p` is a log-probability.

- ...:

  Unused.

## Value

A numeric vector.
