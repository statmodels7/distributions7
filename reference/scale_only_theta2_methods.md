# The Mixed Grid of a Family With No Location

The scale's own pair in closed form and every pair touching a shape by
one central difference of the analytic first-order component.

## Usage

``` r
scale_only_theta2_methods(at = 1L)
```

## Arguments

- at:

  The index of the scale parameter.

## Value

A list of two method bodies, named `grad2` and `hess2`.
