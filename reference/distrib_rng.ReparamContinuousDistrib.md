# Random Generation from a Reparametrized Distribution

The parent's generator at the mapped parameters.

## Usage

``` r
reparam_rng(distrib, n, theta)
```

## Arguments

- distrib:

  A reparametrized distribution.

- n:

  The number of draws.

- theta:

  A named list of the new parameters.

## Value

A numeric vector.
