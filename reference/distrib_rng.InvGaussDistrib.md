# Inverse-Gaussian Random Number Generator

Generates random numbers from the Inverse-Gaussian distribution.

## Arguments

- distrib:

  An `InvGaussDistrib` object.

- n:

  Number of observations to generate.

- theta:

  A list containing the parameters `mu` and `phi`.
