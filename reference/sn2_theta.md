# The Direct Parameters a Centred Triple Implies

Runs
[`sn_cp_to_dp`](https://statmodels7.github.io/distributions7/reference/sn_cp_to_dp.md)
on plain numbers, which every probability function needs before
delegating to
[`skewnormal1_distrib`](https://statmodels7.github.io/distributions7/reference/skewnormal1_distrib.md).

## Usage

``` r
sn2_theta(theta)
```

## Arguments

- theta:

  A list with `mu`, `sigma` and `gamma1`.

## Value

A named list of the direct parameters.
