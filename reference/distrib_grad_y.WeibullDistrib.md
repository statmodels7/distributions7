# Weibull Response Derivative

Closed form: \\\partial \ell / \partial y = (\sigma - 1 - \sigma u)/y\\.

## Arguments

- distrib:

  A `WeibullDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `sigma`.

## Value

A numeric vector.
