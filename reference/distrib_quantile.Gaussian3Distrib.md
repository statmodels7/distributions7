# Gaussian Quantile Function in Mean and Precision

The normal quantile function at standard deviation \\1/\sqrt{\tau}\\.

## Arguments

- distrib:

  A `Gaussian3Distrib` object.

- p:

  A numeric vector of probabilities.

- theta:

  A list with `mu` and `tau`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, `p` is given as a log-probability.

- ...:

  Unused.

## Value

A numeric vector.
