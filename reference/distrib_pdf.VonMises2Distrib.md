# von Mises Density in the Resultant Length

The von Mises density at the concentration \\\kappa = A^{-1}(\rho)\\.

## Arguments

- distrib:

  A `VonMises2Distrib` object.

- y:

  A numeric vector of angles.

- theta:

  A list with `mu` and `rho`.

- log:

  Logical; if `TRUE`, returns the log-density.

## Value

A numeric vector.
