# Truncated Score Mean by Quadrature

The original route for \\\mathbb{E}\_T\[s_i\]\\, kept for the parents
the cdf route cannot serve.

## Usage

``` r
trunc_score_mean_quad(distrib, theta)
```

## Arguments

- distrib:

  A truncated distribution object.

- theta:

  A named list of parameters.

## Value

A named list, one component per parameter.
