# Extract Estimates from a Maximum-Likelihood Fit

Extract Estimates from a Maximum-Likelihood Fit

## Arguments

- object:

  A
  [`distrib_fit`](https://statmodels7.github.io/distributions7/reference/distrib_fit_class.md)
  object.

- scale:

  Either `"parameter"` (default) or `"link"`.

- ...:

  Unused.

## Value

A named numeric vector of estimates.
