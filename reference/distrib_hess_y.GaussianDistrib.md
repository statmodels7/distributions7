# Gaussian Response Second Derivative

Closed-form \\\partial^2 \ell / \partial y^2 = -1/\sigma^2\\.

## Arguments

- distrib:

  A `GaussianDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `sigma`.

## Value

A numeric vector.
