# Geometric Random Generation

Draws through [`rgeom`](https://rdrr.io/r/stats/Geometric.html) at \\p =
1/(1+\mu)\\.

## Arguments

- distrib:

  A `GeometricDistrib` object.

- n:

  The number of draws.

- theta:

  A list containing the parameter `mu`.

## Value

A numeric vector of length `n`.
