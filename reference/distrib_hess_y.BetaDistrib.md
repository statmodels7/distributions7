# Beta Response Second Derivative

Closed-form \\\partial^2 \ell / \partial y^2 = -(\alpha-1)/y^2 -
(\beta-1)/(1-y)^2\\.

## Arguments

- distrib:

  A `BetaDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `phi`.

## Value

A numeric vector.
