# Folded Random Generation

Draws from the parent and takes the absolute value, which is the
definition rather than an approximation of it.

## Arguments

- distrib:

  A `FoldedDistrib` object.

- n:

  The number of draws.

- theta:

  A named list of the parent's parameters.

## Value

A numeric vector of length `n`.
