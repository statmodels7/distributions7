# Default Third Log-CDF Derivatives

The route of
[`cdf_tables`](https://statmodels7.github.io/distributions7/reference/cdf_tables.md)
for the class, put on the requested tail and scale.

## Arguments

- distrib:

  An object inheriting from class `"distrib"`.

- q:

  A numeric vector of quantiles.

- theta:

  A named list of parameters.

- lower.tail:

  Logical.

- log:

  Logical.

- ...:

  Unused.

## Value

A named list of third-derivative components.

A named list of fourth-derivative components.
