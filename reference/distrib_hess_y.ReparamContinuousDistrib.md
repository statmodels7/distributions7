# Second Response Derivative of a Reparametrized Distribution

The parent's, unchanged.

## Arguments

- distrib:

  A reparametrized distribution.

- y:

  The response.

- theta:

  A named list of the new parameters.

- ...:

  Passed to the parent.

## Value

A numeric vector.
