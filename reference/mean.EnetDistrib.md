# Elastic-Net Moments

The density is symmetric about \\\mu\\, so the mean is the location and
the skewness zero. The variance is \\(1+xG)/c\\, which is \\-2\\\partial
\log Z/\partial c\\.

## Arguments

- x:

  An `EnetDistrib` object.

- theta:

  A list containing `mu`, `lambda` and `alpha`.

- ...:

  Ignored.

## Value

A numeric vector.
