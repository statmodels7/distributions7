# Gaussian Quantile Function in Mean and Variance

The normal quantile function.

## Arguments

- distrib:

  A `Gaussian2Distrib` object.

- p:

  A numeric vector of probabilities.

- theta:

  A list with `mu` and `sigma2`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, `p` is given as a log-probability.

- ...:

  Unused.

## Value

A numeric vector.
