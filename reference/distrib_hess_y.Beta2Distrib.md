# Beta Second Response Derivative in Its Shapes

\\\partial^2\ell/\partial y^2 = -(\alpha-1)/y^2 - (\beta-1)/(1-y)^2\\.

## Arguments

- distrib:

  A `Beta2Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list with `alpha` and `beta`.

- ...:

  Unused.

## Value

A numeric vector.
