# Skew Normal Response Derivatives in the Centred Parametrisation

The parent's, unchanged: the coordinates change, the response does not.

## Arguments

- distrib:

  A `SkewNormal2Distrib` object.

- y:

  The response.

- theta:

  A list with `mu`, `sigma` and `gamma1`.

- ...:

  Passed on.

## Value

A numeric vector.
