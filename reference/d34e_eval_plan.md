# Evaluate the Terms of a Derivative Plan

Sums the products of the factors of a plan from
[`d34e_plan()`](https://statmodels7.github.io/distributions7/reference/d34e_plan.md).

## Usage

``` r
d34e_eval_plan(plan, L)
```

## Arguments

- plan:

  A plan.

- L:

  A named list of the derivatives of the log-density, keyed as the
  factors of the plan.

## Value

A numeric vector.
