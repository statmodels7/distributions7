# von Mises Response Hessian

\$\$\dfrac{\partial^2 \ell}{\partial y^2} = -\kappa \cos(y - \mu)\$\$

## Arguments

- distrib:

  A `VonMises1Distrib` object.

- y:

  A numeric vector of angles.

- theta:

  A list containing `mu` and `kappa`.

- ...:

  Unused.

## Value

A numeric vector.
