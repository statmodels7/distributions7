# Generalized Gamma Response Derivatives

Closed form. With \\w = (y/a)^p\\, \\\ell^{(y)} = ((d-1) - pw)/y\\ and
\\\ell^{(yy)} = (pw(1-p) - (d-1))/y^2\\.

## Arguments

- distrib:

  A `GenGamma1Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing `a`, `d` and `p`.

- ...:

  Unused.

## Value

A numeric vector.
