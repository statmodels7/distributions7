# Skew Normal Random Generation in the Centered Parametrization

The parent's generator at the implied parameters.

## Arguments

- distrib:

  A `SkewNormal2Distrib` object.

- n:

  The number of draws.

- theta:

  A list with `mu`, `sigma` and `gamma1`.

## Value

A numeric vector.
