# The Integration Settings in Force

Returns the
[ExpectIntegrate](https://statmodels7.github.io/distributions7/reference/ExpectMethod.md)
object set by
[`set_integration_settings()`](https://statmodels7.github.io/distributions7/reference/set_integration_settings.md),
or an object with the default settings when none is set.

## Usage

``` r
integration_settings()
```

## Value

An
[ExpectIntegrate](https://statmodels7.github.io/distributions7/reference/ExpectMethod.md)
object.
