# Dirichlet Covariance Matrix

\$\$\operatorname{Cov}(Y_i, Y_j) = \dfrac{\delta\_{ij}\mu_i -
\mu_i\mu_j}{\phi + 1}\$\$ singular by construction, the coordinates
summing to a constant.

## Arguments

- distrib:

  A `DirichletDistrib` object.

- theta:

  A named list of parameters.

## Value

A symmetric matrix.
