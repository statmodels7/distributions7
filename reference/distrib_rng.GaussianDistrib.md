# Gaussian Random Number Generator

Generates random numbers from the Gaussian distribution.

## Arguments

- distrib:

  A `GaussianDistrib` object.

- n:

  Number of observations to generate.

- theta:

  A list containing the parameters `mu` and `sigma`.
