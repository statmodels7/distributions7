# Laplace Response Second Derivative

Closed-form \\\partial^2 \ell / \partial y^2 = 0\\ (almost everywhere).

## Arguments

- distrib:

  A `LaplaceDistrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list containing the parameters `mu` and `sigma`.

## Value

A numeric vector of zeros.
