# Beta Distribution Function in Its Shapes

The incomplete beta function.

## Arguments

- distrib:

  A `Beta2Distrib` object.

- q:

  A numeric vector of quantiles.

- theta:

  A list with `alpha` and `beta`.

- lower.tail:

  Logical; if `TRUE`, probabilities are \\P(Y \le q)\\.

- log.p:

  Logical; if `TRUE`, returns log-probabilities.

- ...:

  Unused.

## Value

A numeric vector.
