# Derivatives of the Reciprocal of One Plus a Square

Returns \\d^{j}/da^{j}\\(1+a^{2})^{-1}\\ for \\j = 0, \ldots, 3\\, the
factor the skew normal's shape derivative carries.

## Usage

``` r
recip_1p_sq(a, j)
```

## Arguments

- a:

  A numeric vector.

- j:

  The order, 0 to 3.

## Value

A numeric vector.
