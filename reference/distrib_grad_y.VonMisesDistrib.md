# von Mises Response Gradient

\$\$\dfrac{\partial \ell}{\partial y} = -\kappa \sin(y - \mu)\$\$

## Arguments

- distrib:

  A `VonMisesDistrib` object.

- y:

  A numeric vector of angles.

- theta:

  A list containing `mu` and `kappa`.

- ...:

  Unused.

## Value

A numeric vector.
