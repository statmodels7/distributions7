# Description of an Expectation Method

Returns the sentence that the print method of
[ExpectMethod](https://statmodels7.github.io/distributions7/reference/ExpectMethod.md)
writes for a method, including the sample size of
[`expect_mc()`](https://statmodels7.github.io/distributions7/reference/expect_mc.md)
and the settings of
[`expect_integrate()`](https://statmodels7.github.io/distributions7/reference/expect_integrate.md)
that differ from the defaults.

## Usage

``` r
method_label(x)
```

## Arguments

- x:

  An object inheriting from
  [ExpectMethod](https://statmodels7.github.io/distributions7/reference/ExpectMethod.md).

## Value

A single character string.
