# Multinomial Covariance Matrix

\$\$\operatorname{Cov}(Y_i, Y_j) = n(\delta\_{ij}p_i - p_i p_j)\$\$
singular by construction, the coordinates summing to the size.

## Arguments

- distrib:

  A `MultinomialDistrib` object.

- theta:

  A named list of parameters.

## Value

A symmetric matrix.
