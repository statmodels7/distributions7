# Gaussian Response Derivatives in Mean and Precision

\\\partial\ell/\partial y = -\tau(y-\mu)\\.

## Arguments

- distrib:

  A `Gaussian3Distrib` object.

- y:

  A numeric vector of observations.

- theta:

  A list with `mu` and `tau`.

- ...:

  Unused.

## Value

A numeric vector.
